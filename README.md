# chatgpt-scripts

适用于 ChatGPT 网页端的独立用户脚本集合。每个脚本均位于 `scripts/` 目录下，独立运行，无需 Node.js、构建打包或安装任何依赖。

当前版本：`v2026.09.08-1`

## 脚本列表

支持直接通过 Raw 链接在线安装与更新。

| 脚本名称 | 脚本文件 | 安装地址 | 功能简述 |
| :--- | :--- | :--- | :--- |
| **ChatGPT 模型检测** | `scripts/chatgpt-route-checker.user.js` | [安装链接](https://raw.githubusercontent.com/zjm54321/chatgpt-scripts/main/scripts/chatgpt-route-checker.user.js) | 被动比对请求模型与响应元数据，查看当前路由状态 |
| **Team 助手** | `scripts/team-assistant.user.js` | [安装链接](https://raw.githubusercontent.com/zjm54321/chatgpt-scripts/main/scripts/team-assistant.user.js) | 隐藏上限提示与充值引导，提供席位阈值历史、官方下期账单读取及用量额度统计 |

## 安装与使用

1. 在浏览器中安装用户脚本管理器（如 [Tampermonkey](https://www.tampermonkey.net/) 或 [Violentmonkey](https://violentmonkey.github.io/)）。
2. 点击上表中对应脚本的「安装链接」（Raw 链接）。
3. 脚本管理器会自动打开确认页面，点击「安装」或「确认」（若提示授权 `pay.openai.com` 域名，请点击允许以支持读取官方下期账单）。
4. 刷新 ChatGPT 网页（`https://chatgpt.com`）即可生效。
5. 如已安装旧版独立的监控或用量脚本，请在安装后将其停用或删除并刷新页面，避免重复拦截或冲突。

## 脚本说明与限制

### ChatGPT 模型检测 (`chatgpt-route-checker.user.js`)
- **交互形式**：在 ChatGPT 对话页面右上角原生控制区旁添加纯图标状态按钮，点击展开轻量浮窗，显示 `server_ste_metadata.model_slug`、`request.model` 及 `request.thinking_effort`。
- **状态指示**：自动跟随页面明暗主题。等待/处理中显示时钟或圆点；模型标识一致或属于同一系列显示对勾；存在差异显示警告；缺少元数据或无法比较时显示中性状态。
- **界面适配**：在缺少原生对话顶栏的页面（如工作区或设置页）自动隐藏，回到对话页自动恢复，并避开 Inkstone 扩展按钮位置。
- **网络与隐私**：仅被动监听页面自身的网络请求，不主动向 ChatGPT 发送任何额外请求，不导出对话历史，不读取 Cookie。
- **比对局限**：仅比对接口中暴露的标识符字段，不代表模型实际推理质量或底层算力硬件路由。如遇端点未覆盖、元数据未返回或官方模型别名调整，可能保持未知状态。
- **注意事项**：若此前安装过旧版或其他模型检测脚本，请在安装后停用旧脚本并刷新页面；停用本脚本并刷新即可恢复原生状态。

### Team 助手 (`team-assistant.user.js`)
- **横幅提示隐藏**：仅针对性隐藏标题为「工作区有成员达到使用上限」、正文为「开启自动充值，系统会自动补充额度，避免今后再次中断。」的提示条及同区域内的自动充值按钮。已读取首页和工作空间设置页的实际提示框结构，两处均符合现有文案与控件匹配条件。若混有其他设置项或无关控件则保守跳过。
- **席位阈值历史**：
  - 入口位于成员管理页（`/admin/members`）「邀请成员」左侧的原生圆形通讯录图标按钮，样式与右侧操作按钮对齐；弹窗打开时按钮保持通讯录图标，关闭由弹窗内的关闭按钮负责。
  - 弹窗展示当前工作区记录，按时间倒序展示受影响成员邮箱（未知时标为「邮箱待匹配」）、`vacancy_ordinal`（序数）、`free_vacancy_threshold`（席位阈值）、捕获时间以及 `billing_starts_at` / `expires_at` 起止时间。
  - 仅在用户手动操作时被动监听接口响应，连续相同策略不重复记录，不补抓服务器历史，脚本不主动移除或邀请成员。捕获新的有效席位策略时显示 Toast 提醒；不会因刷新历史重复弹出。支持清空当前空间记录（保留其他空间与邮箱索引）。
- **下期账单与历史发票**：
  - 入口位于账单页（`/admin/billing`）Business 套餐操作行「管理席位」左侧，按钮采用与「管理席位」一致的原生样式，文字为「查看下月账单」。
  - 点击时先同步预留新的官方窗口，再验证当前工作区并导航至官方管理页（重定向至 `pay.openai.com`），仅提取官方页面可见的「下一个账单日期」与「下一笔付款预计」文字，并在两个窗口之间安全回传至原页面展示；下方可同时展示最近最多 10 条历史发票记录。
  - 仅在本次打开的官方窗口与原页面之间回传日期和预计金额，不保存支付会话链接，不读取支付方式、银行卡或开票敏感信息，不会执行支付、订阅或席位变更。
  - 需在脚本管理器中允许访问 `pay.openai.com` 域名（该域名下仅运行轻量读取逻辑，不包含任何 ChatGPT 界面或钩子）。若遇弹窗拦截或窗口阻断未自动返回，可直接查看已打开的官方结算页面。
- **用量与额度统计**：
  - 入口位于个人账户菜单「个性化」下方与「设置」上方，标有钞票图标，恢复用户提供的原版界面、布局与配色；保留现有安全数据接线。
  - 支持「个人用量 / 团队汇总」视图切换（视图切换不改变当前登录账号与工作区）。支持预设周期（本周期/近7天/近30天）及最长 366 天自定义 UTC 日期查询，展示按天与按模型的明细及各类汇总指标；调试槽位仅展示当前显示的汇总数据。
  - 支持用户主动点击导出所显示的汇总数据 CSV/JSON（不包含访问令牌、原始响应或成员信息）。接口受限或缺失项显示为「—」；统计可能存在延迟。
- **模型费用估算与官方定价参考**：
  - 统计费用基于内置单价估算，标明为估算值，不作为官方实际扣费凭据。
  - `gpt-6-astra` 模型单价已核对官方文档（2026-09-08 参考 [模型文档](https://developers.openai.com/api/docs/models/gpt-6-astra) 与 [定价页](https://developers.openai.com/api/docs/pricing)），标准短上下文费率为输入 $10、缓存输入 $1、输出 $50、缓存写入 $12.50 每百万 Token（Fast 模式为 2 倍）；长上下文在单次请求输入超过 272,000 Token 时，全请求输入/缓存/缓存写入按 2 倍、输出按 1.5 倍计费。日级汇总数据无法分辨单次请求的长上下文与缓存写入，实际统计仍按标准短上下文（$10/$1/$50）及 Fast 2 倍单价进行参考估算；其他模型沿用用户提供的参考配置表。
- **网络、存储与隐私**：
  - 横幅隐藏为纯 DOM 操作；席位历史为纯被动监听，仅使用 `_account` Cookie 识别当前空间，不读取登录凭据。沿用旧版席位监控的本地记录；清理网站数据会删除这些记录，共用浏览器时请注意留存的邮箱信息。
  - 账单与用量统计仅在用户主动操作时发起只读 GET 请求，或与本次打开的官方账单窗口进行单次通信；不会上传本地历史到第三方服务。访问令牌与临时统计结果保留在临时内存中，检测到空间切换后清除；席位历史和邮箱索引保存在本机。支持 Web Locks 协调多标签页写入。
- **注意事项**：纯前端辅助工具，不改变工作区实际额度、扣费规则与权限。安装后请停用旧版独立的席位监控或用量追踪脚本并刷新页面，避免重复拦截与冲突。

## 版本与扩展

- **版本规范**：遵循 `vYYYY.MM.DD-N` 命名规则（如 `v2026.09.07-3`、`v2026.09.08-1`），同日发布多次更新时依次递增末尾序号。
- **独立维护**：各脚本保持单文件独立分发，版本更新时可单独安装与升级，无需同步更新未变动的脚本。
- **新增脚本**：欢迎扩充新的用户脚本。所有脚本均需置于 `scripts/` 目录下，保持单文件、可单独安装，不引入外部构建流程与第三方包依赖。
