# chatgpt-scripts

适用于 ChatGPT 网页端的独立用户脚本集合。每个脚本均位于 `scripts/` 目录下，独立运行，无需 Node.js、构建打包或安装任何依赖。

当前版本：`v2026.09.07-2`

## 脚本列表

所有脚本均托管于本仓库的 `scripts/` 目录，支持直接通过 Raw 链接在线安装与更新。

| 脚本名称 | 脚本文件 | 安装地址 | 功能简述 |
| :--- | :--- | :--- | :--- |
| **ChatGPT 模型检测** | `scripts/chatgpt-route-checker.user.js` | [安装链接](https://raw.githubusercontent.com/zjm54321/chatgpt-scripts/main/scripts/chatgpt-route-checker.user.js) | 被动比对请求模型与响应元数据，查看当前路由状态 |
| **Team 助手** | `scripts/team-assistant.user.js` | [安装链接](https://raw.githubusercontent.com/zjm54321/chatgpt-scripts/main/scripts/team-assistant.user.js) | 隐藏上限提示与充值引导，并在成员管理页查看席位阈值变动历史 |

## 安装与使用

1. 在浏览器中安装用户脚本管理器（如 [Tampermonkey](https://www.tampermonkey.net/) 或 [Violentmonkey](https://violentmonkey.github.io/)）。
2. 点击上表中对应脚本的「安装链接」（Raw 链接）。
3. 脚本管理器会自动打开确认页面，点击「安装」或「确认」。
4. 刷新 ChatGPT 网页（`https://chatgpt.com`）即可生效。
5. 如已安装旧版独立监控脚本，请在安装后将其停用或删除并刷新页面。

## 脚本说明与限制

### ChatGPT 模型检测 (`chatgpt-route-checker.user.js`)
- **交互形式**：在 ChatGPT 对话页面右上角原生控制区旁添加纯图标状态按钮，点击展开轻量浮窗，显示 `server_ste_metadata.model_slug`、`request.model` 及 `request.thinking_effort`。
- **状态指示**：自动跟随页面明暗主题。等待/处理中显示时钟或圆点；模型标识一致或属于同一系列显示对勾；存在差异显示警告；缺少元数据或无法比较时显示中性状态。
- **界面适配**：在缺少原生对话顶栏的页面（如工作区或设置页）自动隐藏，回到对话页自动恢复，并避开 Inkstone 扩展按钮位置。
- **网络与隐私**：仅被动监听页面自身的网络请求，不主动向 ChatGPT 发送任何额外请求，不导出对话历史，不读取 Cookie。
- **比对局限**：仅比对接口中暴露的标识符字段，不代表模型实际推理质量或底层算力硬件路由。如遇端点未覆盖、元数据未返回或官方模型别名调整，可能保持未知状态。
- **注意事项**：若此前安装过旧版或其他模型检测脚本，请在安装后停用旧脚本并刷新页面，避免重复拦截或界面冲突；停用本脚本并刷新即可恢复原生状态。

### Team 助手 (`team-assistant.user.js`)
- **横幅提示隐藏**：仅针对性隐藏标题为「工作区有成员达到使用上限」、正文为「开启自动充值，系统会自动补充额度，避免今后再次中断。」的提示条及同区域内的自动充值按钮。已读取首页和工作空间设置页的实际提示框结构，两处均符合现有文案与控件匹配条件。
- **动态页面适配**：页面切换或提示内容变化后会自动重新匹配；若提示框混有其他设置项或无关控件，则保守跳过隐藏。
- **席位历史入口**：仅在成员页（`/admin/members`）标题右侧显示「＋」，点击展开历史记录，默认保持关闭且跟随页面明暗主题；离开该页自动隐藏。
- **记录内容**：弹窗仅展示当前工作区记录，按时间倒序展示受影响成员邮箱（未知时显示「邮箱待匹配」）、`vacancy_ordinal`（序数）、`free_vacancy_threshold`（席位阈值）、捕获时间以及 `billing_starts_at` / `expires_at` 开始与结束时间，空值清晰区分。
- **被动记录机制**：仅在用户自身手动操作时被动监听成员列表与移除操作的响应；缺失策略通知时忽略，连续相同策略不重复记录，`policy_notice: null` 记录为无策略状态。脚本不会主动移除或邀请成员，也不会发起充值；只能记录安装后实际看到的响应。不补抓服务端旧记录，旧脚本已保存在本机的历史继续使用。
- **数据与存储**：仅使用 `_account` 识别当前空间，不读取登录凭据。支持清空当前工作区记录（保留其他空间数据与邮箱别名索引）。邮箱和历史保存在本机；共用浏览器时请注意这些数据会留存。清理网站数据会删除本地历史。
- **并发与依赖**：支持 Web Locks 时协调同一浏览器多个标签页的写入；不支持时为尽力合并。无远程轮询或外部依赖。
- **注意事项**：纯前端辅助，不改变工作区实际额度、扣费规则与权限。若此前已安装独立的席位阈值监控脚本，请在安装本版本后将其停用并刷新页面，避免重复拦截。

## 版本与扩展

- **版本规范**：遵循 `vYYYY.MM.DD-N` 命名规则（如 `v2026.09.07-1`、`v2026.09.07-2`），同日发布多次更新时依次递增末尾序号。
- **独立维护**：各脚本保持单文件独立分发，版本更新时可单独安装与升级，无需同步更新未变动的脚本。
- **新增脚本**：欢迎扩充新的用户脚本。所有脚本均需置于 `scripts/` 目录下，保持单文件、可单独安装，不引入外部构建流程与第三方包依赖。
